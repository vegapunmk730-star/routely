# 🤝 Guia de Contribuição — Waya

Obrigado por quereres contribuir! O Waya só funciona com a comunidade.

---

## 🎯 Como posso ajudar?

### 1. Mapear a tua cidade (não precisas de programar!)

**O que precisas:**
- Um telemóvel com GPS
- O ficheiro `index.html` do Waya
- Conhecimento das paragens da tua cidade

**Passos:**
1. Abre o Waya no telemóvel
2. Vai a **Admin** → define o nome da tua cidade
3. Define o teu perfil de colaborador (nome + tipo)
4. Anda pela cidade e adiciona paragens:
   - Toca no **+** → "Adicionar Paragem"
   - Toca no mapa no sítio exato
   - Tira uma foto
   - Dá nome e zona
5. Liga paragens que conheces:
   - Toca no **+** → "Criar Ligação"
   - Escolhe origem e destino
   - Define tempo estimado
6. Confirma paragens de outros colaboradores:
   - Toca numa paragem → "Confirmo que existe"
7. Exporta os dados:
   - Vai a **Admin** → "Exportar JSON"
   - Partilha o ficheiro!

### 2. Partilhar dados

Exporta o JSON e partilha por:
- 📧 Email
- 💬 WhatsApp / Telegram
- 🐙 Pull Request neste repositório
- 🌐 Cola o JSON numa Issue

### 3. Melhorar o código

**Stack:** Vanilla JavaScript, MapLibre GL, HTML/CSS

**Ideias de melhorias:**
- [ ] Suporte para múltiplos idiomas
- [ ] Filtros por zona/bairro
- [ ] Modo noturno
- [ ] Sincronização peer-to-peer (WebRTC)
- [ ] Versão para iOS/Android nativa
- [ ] Integração com OpenStreetMap (upload de dados)

**Como contribuir código:**
1. Faz fork do repositório
2. Cria uma branch: `git checkout -b minha-feature`
3. Faz commit das tuas alterações
4. Abre um Pull Request

---

## 📋 Regras de qualidade

### Para paragens:
- ✅ Nome claro e reconhecido localmente
- ✅ Foto real do local (não do Google)
- ✅ Coordenadas GPS precisas
- ✅ Zona/bairro correto

### Para ligações:
- ✅ Tempo estimado realista
- ✅ Só ligar paragens que realmente têm transporte entre elas
- ✅ Verificar se a ligação já não existe

### Para verificações:
- ✅ Só confirmar paragens que realmente existem
- ✅ Não confirmar paragens que já verificaste

---

## 🏆 Reconhecimento

Os colaboradores aparecem na **área de Colaboradores** da app com:
- Nome e tipo (Taxista, Passageiro, etc.)
- Número de contribuições
- Número de confirmações
- Histórico de atividades
